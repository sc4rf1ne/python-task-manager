# Python Task Manager

Консольное приложение на языке Python для планирования, отслеживания статуса, поиска и управления пользовательскими задачами с возможностью экспорта данных в JSON-формат.

## Описание проекта
Проект представляет собой модульный менеджер задач, позволяющий пользователям создавать структурированные списки дел, контролировать сроки их выполнения, фильтровать задачи по приоритету, выполнять быстрый поиск по ключевым словам и сохранять историю задач в файлы формата JSON. Приложение разработано с учётом современных практик DevOps и GitHub Flow, покрыто модульными тестами и готово к интеграции в CI/CD конвейеры.

## Возможности
- Добавление новых задач с автоматической валидацией названия и приоритета.
- Отметка задач как выполненных по их идентификатору (ID).
- Удаление неактуальных задач с автоматическим пересчётом счётчиков.
- Просмотр форматированного списка всех текущих задач со статусами `[ ]` / `[x]`.
- Расчёт сводной аналитической статистики (всего задач, выполнено, в работе).
- Регистронезависимый поиск задач по фрагменту ключевого слова.
- Фильтрация задач по уровням приоритета (`Низкий`, `Средний`, `Высокий`).
- Экспорт полного списка задач в файл формата JSON с сохранением кодировки UTF-8.

## Требования
- Операционная система: Windows 10/11, Linux или macOS.
- Установленный интерпретатор Python версии **3.10** или выше.
- Менеджер пакетов `pip` для установки зависимостей.

## Установка
1. Клонируйте репозиторий с платформы GitHub:
```bash
git clone https://github.com/sc4rf1ne/python-task-manager.git
cd python-task-manager
```
2. Создайте и активируйте виртуальное окружение:
```bash
# Windows
python -m venv venv
.\venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```
3. Установите зависимости из файла `requirements.txt`:
```bash
pip install -r requirements.txt
```

## Запуск
Запуск консольного менеджера задач:
```bash
python src/main.py
```

Запуск автоматических модульных тестов:
```bash
python -m unittest discover -s tests -v
```

## Использование
Пример взаимодействия с функциями программы:
```python
from src.main import add_task, complete_task, get_all_tasks, get_task_statistics, export_tasks_to_json

tasks = []

# Добавление задач
add_task(tasks, "Настроить CI/CD пайплайн", "Высокий")
add_task(tasks, "Написать документацию README", "Средний")

# Отметка о выполнении
complete_task(tasks, 1)

# Вывод списка задач
for line in get_all_tasks(tasks):
    print(line)

# Экспорт в файл
export_tasks_to_json(tasks, "tasks_export.json")
```

Пример вывода консоли:
```text
=== КОНСОЛЬНЫЙ МЕНЕДЖЕР ЗАДАЧ (PYTHON TASK MANAGER v2.0) ===
1. [x] Настроить CI/CD пайплайн (Приоритет: Высокий)
2. [ ] Написать документацию README (Приоритет: Средний)
Статистика: всего=2, выполнено=1, в работе=1
```
